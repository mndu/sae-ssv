# SAE-SSV — EMNLP 2025 project page

Website: https://mndu.github.io/sae-ssv/

A static paper website in the same style as SAEExplainer: centered title, author and affiliation block, bracketed resource links, the original framework figure before Overview, and white panels for Overview, Results, and BibTeX.

Results show the steering success-rate columns from Table 1 and the top-ten SAE features from Table 2. Values and author details were checked against the official EMNLP 2025 PDF. The framework image comes from the openly licensed arXiv HTML version.

- Paper: https://aclanthology.org/2025.emnlp-main.112/
- Code: https://github.com/Ineedanamehere/SAE-SSV

Open `index.html` locally to preview. No build process is required.
